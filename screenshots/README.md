# Screenshots Guide

After launching the dashboard, capture these screens for your report and presentation:

```bash
streamlit run streamlit_app.py
```

## Recommended Captures

| Filename | Page | Content |
|----------|------|---------|
| `home.png` | Home | Architecture overview & metrics |
| `live_prediction.png` | Live Prediction | Input text + confidence bars |
| `conversation_simulator.png` | Conversation Simulator | Emotion timeline chart |
| `analytics.png` | Analytics Dashboard | Heatmap & distribution |
| `training_results.png` | Training Results | Accuracy/loss curves |

Training plots are auto-generated in `outputs/`:
- `training_accuracy_loss.png`
- `confusion_matrix.png`
- `emotion_distribution.png`

Copy or screenshot Streamlit pages into this folder for submission.
